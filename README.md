# scan-marked-papers

已批改试卷上传、错题扫描、预切、计算题拆分、学生关联及同步检查技能。接口优先，浏览器补足。

下载 [安装包](scan-marked-papers.zip)，解压至 `~/.codex/skills/`，保留 `scan-marked-papers/` 目录。其他智能体可读取 [SKILL.md](SKILL.md) 及其引用文件使用。

需要自己的批阅台账号和对应学校、课程、班级权限。仓库不含凭证、试卷或学生数据。

真实验收覆盖23份试卷、15道独立题（含6道独立计算题）、345条作答，媒体准备及同步检查通过；未提交课堂导入，学生订正未验证。
